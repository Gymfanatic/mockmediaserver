Mock Media Server API Documentation

This is a simple API for managing media data.

API Endpoints

GET /media

Returns a list of all media items stored on the server.

POST /media

Allows you to add a new media item. The request body should contain a JSON object with the following format:

  {
    "name": "Media Name",
    "url": "http://example.com/media.jpg"
  }

Example cURL Commands

  curl -X GET http://localhost:3000/media

  curl -X POST http://localhost:3000/media -H "Content-Type: application/json" -d '{"name": "New Media", "url": "http://example.com/media.jpg"}'
